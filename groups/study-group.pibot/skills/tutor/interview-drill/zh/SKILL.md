# 面试式练习

主题：{主题}　当前水平：{水平}

## 步骤
1. 每轮只取一个考点，从主题或上一次答错的地方挑，其余先不提。学习者没给主题时，这一轮的唯一问题就是确认要练哪个点。
2. 第一问做成单字母可答的题：题干一句话，选项 A–D 各一行，并写明「回一个字母即可」。不出要写代码、写长答案或猜没讲过的内容的题。
3. 答对后不急着换考点：要求学习者按「主体 / 资源 / 动作 / 条件」四栏用自己的话复述刚才的结论。哪一栏空着或说错，就只追问那一栏。
4. 答错时指出错在哪，给一个最小提示（一个方向、一个反例或一组对比），然后把同一个考点换一种问法再问一次。提示后仍答错才讲解，并把这一点记进待回顾。
5. 每过 2–3 个考点回顾一次待回顾里的点，换个情境再问；同一考点答对两次才移出待回顾。
6. 每轮回复的最后一个问题只有一个：不并列追问，不预告下一题，不在同一条回复里连问两问。

## 复述模板
```
- 主体：谁或什么（对象、组件、角色）
- 资源：用到什么数据、文件、工具或输入
- 动作：发生了什么变化、先后顺序如何
- 条件：在什么前提下成立，什么情况下不成立或出错
```

## 节奏与计划
- 练习对话不建 TODO 计划，也不写「学习计划.md」；每轮只做一问一答这一步，等学习者回答再继续。
- 只有跨天的学习安排（几周的复习表、每天练什么）才用计划，或建议用户建例行任务；这类安排交给「复习计划」（study-plan）技能，本技能只做单次练习。

## 使用边界

优先使用已有信息；用户的数量、格式和任务范围优先于本文默认模板。工具权限、主目录/附加只读、Plan 模式与预算以当次实际能力为准；不换工具规避拒绝。这里只给工作方法，不授权写入、命令、付费、发送、提交或发布；未执行/验证的步骤如实标明。
