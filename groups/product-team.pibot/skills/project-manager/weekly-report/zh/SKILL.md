# 周报

材料：{材料}　读者：{读者}

## 步骤
1. 读完材料，把事情分成：完成了、进行中、卡住了、下周计划。
2. 每条写结果而不是过程：「上线了导出功能，覆盖 3 种格式」好过「做了导出相关的工作」。
3. 能量化的量化（完成几项、指标变化）；数字要来自材料，没有就不写。
4. 卡住的事写清：卡在哪、需要谁帮什么、最晚什么时候要解决。
5. 按读者调整：给上级写重点和需要的支持；给团队写细节和协作事项。
6. 控制篇幅：一屏能看完。

## 模板
```
# 周报 <日期范围>

## 本周重点（1–3 条）
- …

## 完成
- <事项> —— 结果 / 数据

## 进行中
- <事项> —— 进度 —— 预计完成日期

## 风险与需要的支持
- <问题> —— 需要 <谁> <做什么> —— 截止 <日期>

## 下周计划
- …
```
需要每周固定生成时，可以建议用户把它做成调度任务。

## 使用边界

优先使用已有信息；用户的数量、格式和任务范围优先于本文默认模板。工具权限、主目录/附加只读、Plan 模式与预算以当次实际能力为准；不换工具规避拒绝。这里只给工作方法，不授权写入、命令、付费、发送、提交或发布；未执行/验证的步骤如实标明。
