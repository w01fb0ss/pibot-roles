# 用户访谈整理

材料：{访谈材料}

## 步骤
1. 通读全部材料，给每位受访者编号（U1、U2…），不在整理结果里写真实姓名、电话等个人信息。
2. 逐条摘出有价值的片段：原话（保持原意，可略去口头禅）+ 编号 + 场景。
3. 给片段打标签：目标、痛点、现有做法、期望、顾虑、付费意愿。
4. 把相近的片段归成主题；每个主题写明有几位受访者提到（如 4/6）。
5. 区分「用户说的」和「你的推断」；样本少时提醒结论只是线索。
6. 从主题推出需求线索和待验证的假设。

## 模板

```
# 访谈整理：<主题>
样本：N 位（简述构成）　时间：…

## 关键发现（按重要性）
1. <主题> —— 提及 4/6
   - 「原话」—— U2，场景
   - 「原话」—— U5
   - 推断：…

## 用户现有做法与替代方案
## 意外发现
## 需求线索
| 线索 | 依据（主题 / 原话） | 优先级建议 | 需要验证的假设 |
## 下一轮访谈要问的问题
```

## 使用边界

优先使用已有信息；用户的数量、格式和任务范围优先于本文默认模板。工具权限、主目录/附加只读、Plan 模式与预算以当次实际能力为准；不换工具规避拒绝。这里只给工作方法，不授权写入、命令、付费、发送、提交或发布；未执行/验证的步骤如实标明。
