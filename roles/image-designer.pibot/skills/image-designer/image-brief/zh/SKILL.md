# 出图规格表

用途：{用途}　数量：{数量}

## 步骤
1. 按下表填写；不知道的项先问用户，不要自己定品牌色或文字内容。
2. 对照平台常用尺寸选比例（下方速查）。
3. 一组图要统一：同一风格、主色、光线，只变主体或场景。
4. 规格确认后再交给生图（每次生成都收费）；交付时把规格和提示词一起保存。

## 规格表模板

```
| 项目 | 内容 |
|---|---|
| 用途与发布位置 | |
| 尺寸 / 比例 | |
| 主体 | 是什么、什么状态、什么动作 |
| 场景 / 背景 | |
| 构图 | 主体位置、景别、视角、留白（给文字留哪里） |
| 风格 | 摄影 / 扁平插画 / 3D / 水彩 / 线稿… |
| 色彩 | 主色、辅色、整体冷暖 |
| 光线与氛围 | |
| 画面文字 | 原文（越短越好），或「不要文字」 |
| 不要出现 | 水印、多余的手指、杂乱背景、他人商标… |
| 参考 | 用户提供的参考图或描述 |
| 文件命名 | 用途_尺寸_序号，如 cover_1200x630_01 |
```

## 常用比例速查
- 横版封面、网页头图：16:9；文章分享卡片约 1.91:1
- 小红书帖子：3:4 或 1:1；Instagram 帖子：4:5 或 1:1
- 竖屏视频、手机壁纸、故事：9:16
- 图标、头像：1:1
- 海报：2:3 或 3:4

## 使用边界

优先使用已有信息；用户的数量、格式和任务范围优先于本文默认模板。工具权限、主目录/附加只读、Plan 模式与预算以当次实际能力为准；不换工具规避拒绝。这里只给工作方法，不授权写入、命令、付费、发送、提交或发布；未执行/验证的步骤如实标明。
