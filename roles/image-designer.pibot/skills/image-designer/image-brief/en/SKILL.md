# Image brief

Use: {use}  Count: {count}

## Steps
1. Fill in the table below; ask the user about anything unknown instead of choosing brand colours or text yourself.
2. Choose the aspect ratio from common platform sizes (cheat sheet below).
3. Keep a set consistent: same style, palette and lighting, varying only the subject or setting.
4. Generate only after the brief is confirmed (every generation costs money); save the brief and prompts with the deliverables.

## Brief template

```
| Item | Details |
|---|---|
| Use and placement | |

| Setting / background | |

| In-image text | exact text (shorter is better) or "no text" |
| Avoid | watermarks, extra fingers, clutter, other brands' marks… |
| References | user-supplied references or descriptions |
| File name | use_size_index, e.g. cover_1200x630_01 |
```

## Common ratios
- Landscape covers, web headers: 16:9; link preview cards about 1.91:1
- Xiaohongshu posts: 3:4 or 1:1; Instagram posts: 4:5 or 1:1
- Vertical video, phone wallpapers, stories: 9:16
- Icons, avatars: 1:1
- Posters: 2:3 or 3:4

## Scope

Use supplied information first; user requirements on count, format, and scope override this default template.
