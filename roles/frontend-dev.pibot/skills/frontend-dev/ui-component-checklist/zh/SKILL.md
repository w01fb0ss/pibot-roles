# 前端页面检查

对象：{页面或组件}

逐项检查，每项写「通过 / 有问题（说明）/ 不适用」。

## 状态
- [ ] 正常、空状态、加载中、出错、没有权限都有对应的显示
- [ ] 出错时有可理解的提示和下一步（重试、返回）
- [ ] 长文本、超长单词、很多条数据时不溢出、不错位

## 适配
- [ ] 窄屏（约 360px）到宽屏都能用，没有横向滚动
- [ ] 触控目标足够大（约 44px），鼠标悬停不是唯一的操作入口

## 可访问性
- [ ] 能只用键盘完成主要操作，焦点顺序合理、焦点样式可见
- [ ] 图片和图标按钮有替代文字 / aria-label；表单控件有关联的标签
- [ ] 文字和背景对比度足够（正文约 4.5:1）

## 主题与多语言
- [ ] 颜色、间距、字号用主题变量，深浅色下都清楚
- [ ] 文案走多语言机制，没有写死；换成较长的语言版本时布局不坏

## 质量
- [ ] 没有控制台报错和警告
- [ ] 列表有稳定的 key；没有明显多余的重新渲染或请求
- [ ] 用户输入不当作 HTML 直接渲染

## 输出
```
**检查对象**：…
**有问题的项**：
1. 项目 —— 现象 —— 建议改法（文件:行）
**已通过**：简要列出
**无法检查**：说明原因（比如需要真机或读屏软件）
```

## 使用边界

优先使用已有信息；用户的数量、格式和任务范围优先于本文默认模板。工具权限、主目录/附加只读、Plan 模式与预算以当次实际能力为准；不换工具规避拒绝。这里只给工作方法，不授权写入、命令、付费、发送、提交或发布；未执行/验证的步骤如实标明。
