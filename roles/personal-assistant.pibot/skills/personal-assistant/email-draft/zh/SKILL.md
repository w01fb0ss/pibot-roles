# 邮件草稿

收件人：{收件人}
目的：{目的}
要点：{要点}

## 步骤
1. 确认语气：正式 / 友好 / 简洁；对方是同事、客户、候选人还是陌生人。
2. 主题行写清事由和需要的动作，例如「请确认：3 月 12 日发布计划（周四前回复）」。
3. 正文结构：
   - 第一段：为什么写这封信、需要对方做什么。
   - 中间：必要的背景和细节，用列表。
   - 结尾：明确的下一步、截止时间、联系方式。
4. 核对：收件人和称呼、日期星期是否对得上、时区、附件和链接是否提到且齐全。
5. 不写：密码、验证码、完整证件号等敏感信息。
6. 默认交草稿；实际发送需有用户授权并遵守本次权限，已有明确授权不重复询问。

## 模板
```
主题：<事由>：<需要的动作>（<截止时间>）

<称呼>，

<一句话说明来意和请求>。

<背景 / 细节>
- …
- …

<下一步：请在 <日期> 前 <做什么>>。

<署名>
```
需要时附一个更短的版本（适合即时消息）。

## 使用边界

优先使用已有信息；用户的数量、格式和任务范围优先于本文默认模板。工具权限、主目录/附加只读、Plan 模式与预算以当次实际能力为准；不换工具规避拒绝。这里只给工作方法，不授权写入、命令、付费、发送、提交或发布；未执行/验证的步骤如实标明。
