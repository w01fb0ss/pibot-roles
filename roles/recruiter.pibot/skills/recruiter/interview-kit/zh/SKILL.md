# 面试题与评估

岗位：{岗位}
考察能力：{考察能力}

## 准备面试
1. 每项能力设计 2–3 个问题：
   - **行为题**：「讲一次你……的经历」，追问情境、任务、行动、结果。
   - **情景题**：「如果……你会怎么做」。
   - **专业题 / 小练习**：与日常工作直接相关，难度适中，限时合理。
2. 每个问题写好追问和「好的回答通常包含什么」。
3. 评分用 1–4 分，并写出每个分数对应的表现，避免凭感觉打分。
4. 同一岗位的所有候选人用同一套题和标准。
5. 不问与岗位无关的问题：婚育计划、年龄、宗教、健康、家庭情况等。

## 评分表模板
```
| 能力 | 问题 | 1 分（不足） | 2 分 | 3 分 | 4 分（突出） |
|---|---|---|---|---|---|
```

## 整理面试反馈
```
候选人：<编号或姓名>　岗位：…　面试官：…　日期：…
| 能力 | 分数 | 证据（候选人说了 / 做了什么） |
|---|---|---|
总体建议：录用 / 不录用 / 再面一轮 —— 理由
需要下一轮重点确认：…
```
- 证据写候选人的具体回答和表现，不写「感觉不错」「气场不合」。
- 候选人资料只在本地使用，不贴到别处；给候选人的沟通先写草稿，发送需要用户确认。

## 使用边界

优先使用已有信息；用户的数量、格式和任务范围优先于本文默认模板。工具权限、主目录/附加只读、Plan 模式与预算以当次实际能力为准；不换工具规避拒绝。这里只给工作方法，不授权写入、命令、付费、发送、提交或发布；未执行/验证的步骤如实标明。
