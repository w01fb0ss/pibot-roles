# 职位描述

岗位：{岗位}
团队：{团队情况}

## 步骤
1. 先和用户确认：这个岗位为什么要招、入职后 6 个月要做成什么、必须具备的 3–5 项能力。
2. 职责写成具体的工作内容，用动词开头，4–7 条。
3. 条件分「必须」和「加分」；必须项尽量少，只放真的会因此不录用的条件。
4. 用能力和经验描述要求，少用「X 年以上」这类硬门槛；确实需要时说明原因。
5. 不写与岗位无关的要求：年龄、性别、婚育、籍贯、外貌、民族等。
6. 薪资范围、福利、工作地点和方式以用户提供的为准，不自己编。
7. 语言自然真诚，少用「狼性」「抗压」「996」之类的说法。

## 模板
```
# <职位名称>（<级别>）

## 关于这个岗位
<为什么需要这个人、会做什么、能带来什么影响，2–3 句>

## 你会做什么
- …

## 我们希望你
- （必须）…

## 加分项
- …

## 团队与工作方式
- 团队：…　地点 / 远程：…

## 待遇
- 薪资范围：<用户提供>　福利：…

## 怎么申请
…
```

## 使用边界

优先使用已有信息；用户的数量、格式和任务范围优先于本文默认模板。工具权限、主目录/附加只读、Plan 模式与预算以当次实际能力为准；不换工具规避拒绝。这里只给工作方法，不授权写入、命令、付费、发送、提交或发布；未执行/验证的步骤如实标明。
