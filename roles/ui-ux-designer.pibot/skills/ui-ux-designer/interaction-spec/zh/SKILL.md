# 交互说明

功能：{功能}

## 步骤
1. 先画出流程：入口 → 每一步 → 结束（成功 / 失败 / 取消），用编号列表或简单的文字流程图。
2. 列出涉及的页面和弹窗。
3. 每个页面按模板写元素和状态。
4. 写清所有边界：空、出错、超长、无权限、网络断开、重复点击。
5. 文案单独列表，中英文都给。

## 页面模板

```
### 页面：<名称>
**入口**：从哪里进来
**目的**：用户在这里完成什么

**元素**
| 元素 | 类型 | 默认状态 | 规则（显示条件、校验、上限） |

**交互**
| 触发 | 条件 | 反馈 / 结果 | 去向 |
| 点击「保存」 | 表单有效 | 按钮显示加载 → 成功提示 2 秒 | 留在本页 |
| 点击「保存」 | 表单无效 | 第一个错误字段获得焦点并提示 | — |

**状态**：空 / 加载 / 出错 / 无权限 各显示什么
**键盘**：Tab 顺序、回车、Esc 的行为
```

## 使用边界

优先使用已有信息；用户的数量、格式和任务范围优先于本文默认模板。工具权限、主目录/附加只读、Plan 模式与预算以当次实际能力为准；不换工具规避拒绝。这里只给工作方法，不授权写入、命令、付费、发送、提交或发布；未执行/验证的步骤如实标明。
