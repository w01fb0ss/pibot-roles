# 接口文档

## 步骤
1. 从源码和类型定义里读出接口，不靠猜；源码和现有文档不一致时，以源码为准并在回复里指出。
2. 先写概览：认证方式、基础地址、通用的错误格式、分页方式、版本。
3. 每个接口按下面的模板写。
4. 示例用编造的数据；令牌写成 <YOUR_TOKEN>。
5. 默认不运行命令：示例请求和响应标注「未运行验证」，不编造执行结果，或请开发同事确认。

## 单个接口模板

```
### <方法> <路径>（或函数名）
<一句话用途>

**权限**：谁可以调用

**参数**
| 名称 | 位置（路径 / 查询 / 请求体） | 类型 | 必填 | 默认值 | 说明 |

**返回**
| 字段 | 类型 | 说明 |

**错误**
| 错误码 / 状态码 | 含义 | 调用方怎么处理 |

**示例**
请求：
（curl 或代码片段）
响应：
（JSON）

**注意**：限流、幂等、分页、废弃计划等
```

优先使用已有信息；用户的数量、格式和任务范围优先于本文默认模板。工具权限、主目录/附加只读、Plan 模式与预算以当次实际能力为准；不换工具规避拒绝。这里只给工作方法，不授权写入、命令、付费、发送、提交或发布；未执行/验证的步骤如实标明。
