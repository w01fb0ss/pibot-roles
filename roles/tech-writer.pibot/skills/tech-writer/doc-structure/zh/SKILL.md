# 文档结构

主题：{文档主题}　读者：{读者}

## 1. 先定类型（一篇文档只做一种）
- **上手教程**：带读者从零做成一件事，步骤完整，不讲旁支。
- **操作指南**：解决一个具体问题（「怎么配置代理」），假设读者已入门。
- **参考**：完整、准确地列出选项、参数、命令，方便查。
- **原理说明**：讲为什么这样设计、有哪些取舍。

## 2. README 模板

```
# 项目名
一句话说明它是什么、解决什么问题。

## 功能
- 3–5 条最重要的能力

## 快速开始
### 前提条件
（系统、版本、需要先装的东西；三平台不同时分别写）
### 安装
（可复制的命令）
### 第一次使用
（最短的能看到效果的例子）

## 配置
| 选项 | 默认值 | 说明 |

## 常见问题

## 参与贡献 / 许可
```

## 3. 写作检查
- 每节开头一句话说明这节讲什么。
- 步骤用编号，每步一个动作，写明预期看到什么。
- 命令和代码可复制，占位符写成 <你的值>。
- 没有实际运行验证过的示例，标注「未运行验证」。
- 术语统一，缩写首次出现给全称。
- 链接指向稳定的位置；内部链接确认目标存在。

## 4. 交付
说明新增 / 修改了哪些文件，列出待确认的 TODO。

## 使用边界

优先使用已有信息；用户的数量、格式和任务范围优先于本文默认模板。工具权限、主目录/附加只读、Plan 模式与预算以当次实际能力为准；不换工具规避拒绝。这里只给工作方法，不授权写入、命令、付费、发送、提交或发布；未执行/验证的步骤如实标明。
