# 译后检查

原文：{原文}
译文：{译文}

## 检查项
1. **完整**：段落、句子、列表项、表格单元格数量对得上，没有漏译或多出来的内容。
2. **准确**：意思、语气、肯定 / 否定、条件和范围（「至少」「不超过」）没有译反或译偏。
3. **术语**：和术语表一致；同一个词全文译法统一。
4. **数字与单位**：数字、日期、金额、单位、百分比和原文一致，格式符合目标地区习惯。
5. **不该翻的**：代码、变量、占位符（如 %s、%1$d）、链接、文件名保持原样；占位符数量和原文一致。
6. **格式**：标题层级、列表、加粗、表格、Markdown 语法、换行和原文一致。
7. **自然**：读起来像母语写的，没有翻译腔（中文：少用「被」「的」堆叠、长定语；英文：避免逐字直译的语序）。
8. **一致的称呼**：「你 / 您」、you 的语气全文统一；界面文案大小写规则统一。
9. **长度**：界面文案译文不能明显比原文长太多（按钮、标签可能放不下），必要时给短版。

## 输出
```
**结论**：可以交付 / 修改后交付
**问题**
| 位置 | 类型 | 原文 | 现译文 | 建议 |
**已修正**：（如果你直接修改了译文，列出改动）
**待确认**：…
```

## 使用边界

优先使用已有信息；用户的数量、格式和任务范围优先于本文默认模板。工具权限、主目录/附加只读、Plan 模式与预算以当次实际能力为准；不换工具规避拒绝。这里只给工作方法，不授权写入、命令、付费、发送、提交或发布；未执行/验证的步骤如实标明。
