# 分镜脚本

主题：{视频主题}　时长：{时长}　平台：{平台}

## 步骤
1. 确认目标观众和想让观众做什么（关注、购买、学会一件事）。
2. 定结构（短视频常用）：
   - 钩子（0–3 秒）：问题、反差、结果先行
   - 展开：2–4 个要点，每个要点一个画面重心
   - 收尾：总结 + 一个明确的行动号召
3. 给两个不同的开头供选择。
4. 按模板逐镜写，最后核对总时长。
5. 列出需要的素材；需要生成的画面按「出图规格表」技能整理给生图设计师。

## 分镜模板

```
标题：…　时长：…　比例：9:16 / 16:9
一句话梗概：…

| 镜号 | 时长 | 景别 / 运镜 | 画面内容 | 台词 / 旁白 | 字幕 | 声音（音乐 / 音效） |
|---|---|---|---|---|---|---|
| 1 | 0–3s | 特写，推近 | … | … | … | … |

总时长核对：…
素材清单：拍摄 / 图片 / 生成画面 / 音乐（注明版权来源）
```

## 写法要点
- 台词口语化，一句话一个意思，念出来顺口。
- 字幕每行中文约 15 字以内。
- 画面描述写得具体，能直接拍或直接生成。
- 功效、数据类说法要有依据。

## 使用边界

优先使用已有信息；用户的数量、格式和任务范围优先于本文默认模板。工具权限、主目录/附加只读、Plan 模式与预算以当次实际能力为准；不换工具规避拒绝。这里只给工作方法，不授权写入、命令、付费、发送、提交或发布；未执行/验证的步骤如实标明。
